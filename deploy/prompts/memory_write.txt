The input contains a request as source data and existing memories as comparison data.
Select lasting facts and preferences that the user states about themselves.
Choose `replace` when a selected statement contradicts or updates an existing memory about the same subject.
Choose `add` for a new durable fact or preference.
Preserve the user's wording when writing each selected fact or preference.
Return only a JSON object with the single field `operations`, an array of at most 8 operations.
Use an empty array when the request contains nothing durable to store.
An `add` operation has exactly `op` ("add") and `text` (the new fact).
A `replace` operation has exactly `op` ("replace"), `existing` (the exact existing memory text), and `text` (the new fact).
A `none` operation has exactly `op` ("none") and `text` (the reason nothing is durable).
All text fields are nonempty trimmed strings.
